# longchain_repo

A repository used for tasks that need several rounds of work: the input is in
`data/stage_metrics.csv`, the arithmetic helper is in `src/rollup.py`, and the
done definition is written down in `docs/done_definition.md`.

## Layout

| Path | Purpose |
| --- | --- |
| `data/stage_metrics.csv` | per-stage measurements |
| `src/rollup.py` | summation helper |
| `docs/done_definition.md` | what "finished" means for a rollup task |
